# 手写于日常

把真实手写笔迹变成透明贴纸，放进日常照片。

## 使用
双击 index.html，用浏览器打开，无需安装、模型、API 密钥或联网。两张初始照片已内置。

1. 将图片拖进「背景照片」和「手写照片」对应区域，或通过按钮选择。
2. 调整去背景强度，保留笔画、去除纸张。
3. 在预览画面拖动笔迹，调整大小、旋转、颜色和透明度。
4. 下载合成 PNG，或者单独下载透明手写 PNG。

合成图保留背景原图尺寸。拖入的新图片只保留在本次浏览器会话中，刷新后恢复初始照片。

## 原理
使用原生 HTML、CSS、JavaScript 和 Canvas。亮度 L = 0.2126R + 0.7152G + 0.0722B。
透明度 alpha = 255 × clamp((阈值 − L) / 32, 0, 1)。浅色纸张透明，深色笔迹保留，边缘平滑过渡。
提取后按可见像素边界裁剪，再通过画布平移、缩放、旋转合成。默认笔迹会按颜色控件重新着色。
适用于浅背景、深色笔迹；较暗阴影和污点可能被保留。

## 文件
- index.html：完整应用，含两张初始照片，无外部依赖。
- .nojekyll：GitHub Pages 静态站点标记。

访客自行拖入的照片仅在各自浏览器处理，不会上传。
